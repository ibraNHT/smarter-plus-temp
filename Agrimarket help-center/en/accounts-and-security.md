# Accounts & Security

This guide explains account setup, login security, and verification controls.

## Account basics

- Each account uses a unique email and phone number.
- Keep your profile data accurate and updated.
- You are responsible for activity on your account.

## Login and sessions

- Login supports email or phone identifier.
- Use logout on shared devices.
- Token/session errors can happen if your session expires; sign in again.

## Password reset

1. Request reset from the login page.
2. Use the reset link/token promptly.
3. Create a strong new password.

If reset fails, request a new reset token.

## OTP verification (security-sensitive actions)

The platform may require OTP verification for specific actions, especially for producers, such as:

- withdrawal requests
- certain profile updates (e.g., sensitive identity/phone changes)

If asked for OTP:

1. Request OTP.
2. Verify OTP.
3. Complete action with the returned verification token/header where required.

## Producer profile status

Producer accounts can be in different states (for example pending, validated, suspended).  
Some seller actions are blocked until validation is complete.

## Security best practices

- Use a unique password.
- Do not share credentials or OTP codes.
- Avoid using unknown/public devices for account actions.
- Report suspicious access quickly to **helpdesk@aheteici.com**.
