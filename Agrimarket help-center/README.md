# Agrimarket Connect Help Center

This Help Center is the customer-facing documentation set for **Clients** and **Producers** using Agrimarket Connect marketplace and retail services.

## How to use this Help Center

- Start with **Getting Started** and **Accounts & Security**
- Then follow role-specific guides:
  - Clients: Marketplace Buying + Orders + Payments
  - Producers: Selling + Orders + Withdrawals
- Use **FAQ** and **Troubleshooting** for quick answers
- Check **Policy Links** for legal/privacy context
